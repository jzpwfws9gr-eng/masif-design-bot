# V84.0.8 — نسخة دور 32 السريعة

هذه النسخة مخصصة للوضع الحالي بعد اعتماد أن البطولة داخل البوت تبدأ من دور 32 فقط.

## المهم في النسخة
- تصميم مباريات اليوم من جدول دور 32 الثابت فقط.
- اليوم الرياضي = PM اليوم + AM اليوم التالي.
- مباشر الآن يعرض مباريات دور 32 فقط، ولا يعرض `تحدد لاحقًا`.
- ESPN يستخدم للنتيجة والبلنتيات فقط، وليس لتحديد المباريات.
- مسابقات المصيف:
  - أي منتخب غير موجود في دور 32 يعتبر غادر.
  - خاسر دور 32 بالوقت الأصلي أو بالبلنتيات يعتبر غادر.
  - فائز البلنتيات يبقى مستمر.
- إلغاء لوحة البطولة، مسار التأهل، الشجرة، الإحصائيات العامة، أفضل الثوالث، وكيف تتأهل.
- /start و /ping خفيفة.
