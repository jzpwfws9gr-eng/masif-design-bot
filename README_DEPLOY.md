# V84.1.2 — إصلاح الفائز من نتائج البوت فقط

## التعديل المعتمد
- لوحة البطولة / مسار البطولة / إشعارات التأهل والمغادرة لا تسحب من ESPN وقت العرض.
- المصدر هو نتائج المباريات المحفوظة داخل البوت فقط.
- نتيجة المباراة الإقصائية تُقرأ بهذا المنطق:
  1. انتهت المباراة: الفريق 1 X-X الفريق 2
  2. إذا فيه ركلات ترجيح محفوظة: انتهت ركلات الترجيح الفريق 1 X-X الفريق 2
  3. الفائز: الفريق صاحب winner المحفوظ أو صاحب الترجيح الأعلى أو صاحب النتيجة الأعلى.
- إذا انتهت مباراة إقصائية بالتعادل ولا يوجد winner ولا ركلات ترجيح محفوظة، لا يتم ترحيل أي منتخب حتى تُحدّث النتيجة.

## مهم
لا يوجد اتصال ESPN من زر لوحة البطولة أو زر مسار البطولة. ESPN يبقى فقط ضمن نظام تحديث النتائج الموجود أصلًا في البوت.

## التشغيل
استبدل ملفات النسخة السابقة بهذه الملفات ثم شغل البوت كالمعتاد.
