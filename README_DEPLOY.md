# بوت فانتزي المصيف فقط

هذه النسخة نظيفة ومخصصة للفانتزي فقط.

تم حذف التشغيل والربط الخاص بـ:
- بث مباشر
- ESPN ومواقع النتائج
- نتائج المباريات العامة
- المسابقات الخارجية
- ترتيب المجموعات والأخبار والمتأهلين

الموجود:
- إضافة التشكيلات واحتساب النتائج
- اعتماد النتائج والقفل
- الترتيب العام والإحصائيات
- صور اليوم والترتيب والأساطير والبطاقات
- تقرير الفترة وملف الإحصائيات PDF
- إدارة المشاركين
- النسخ الاحتياطي والاسترجاع
- كأس الفانتزي

## التشغيل
ضع BOT_TOKEN في متغيرات البيئة.
اختياريًا ضع ADMIN_IDS لقفل أوامر الإدارة.

شغّل:
```bash
python bot.py
```
