- صورة مسابقة أبوخالد/أبوياسر لم تعد تدخل في حسابات ثقيلة عند الضغط.

- لا يسحب ESPN عند فتح المسابقة.
- لا يقرأ مسار البطولة أو التأهل أو إحصائيات البطولة عند فتح المسابقة.
- الحالة الآن تعتمد على دور 32 فقط:
  - خارج دور 32 = غادر
  - الخاسر المعروف حاليًا من دور 32 = غادر
