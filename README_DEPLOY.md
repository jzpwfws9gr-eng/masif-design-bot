# نسخة معدلة اعتماد فهد V83 — الأدوار الإقصائية ومسابقات المصيف

مبنية على V82 مع التعديلات التالية:

- إخفاء زر أفضل الثوالث بعد نهاية دور المجموعات.
- إخفاء زر مباريات دور الـ32 من القائمة.
- إضافة زر رئيسي: 🏆 الأدوار الإقصائية.
- داخل الأدوار الإقصائية:
  - 🏟️ دور الـ16
  - 🏟️ ربع النهائي
  - 🏟️ نصف النهائي
  - 🥉 الثالث والرابع
  - 🏆 النهائي
  - 📅 كل الأدوار
- إبقاء تصميم مباريات اليوم كما هو، مع حل أسماء أطراف الأدوار الإقصائية من نتائج المباريات بدل “لم يتحدد” عند معرفة الفائز.
- دور الـ32 تم تثبيت أطرافه داخل الكود بعد اكتماله، مع ربط الفائزين تلقائيًا بدور الـ16 ثم ربع النهائي ثم نصف النهائي ثم النهائي والثالث والرابع.
- إضافة زر ظاهر للجميع: 🏆 مسابقات المصيف.
- لا يفتح زر مسابقات المصيف للعامة إلا بالرقم السري: كرت احمر.
- المشرف يدخل المسابقات بدون رقم سري.
- إضافة زري مشرف داخل لوحة الإدارة:
  - 🏆 مسابقة أبوخالد
  - 🏆 مسابقة أبوياسر
- المسابقات تظهر كتصميم صورة بخلفية زرقاء مثل مباريات اليوم بدون تمثال.
- مسابقة أبوخالد ثابتة داخل الكود: المشارك / المنتخب.
- مسابقة أبوياسر ثابتة داخل الكود: المشارك / المنتخب / اللاعب.
- إذا منتخب المشارك غادر، يظهر السطر بشطب أحمر خفيف في التصميم.
