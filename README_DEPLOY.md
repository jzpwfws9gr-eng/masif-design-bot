# V1 — بوت مسابقة المصيف اليدوي من الصفر

هذه نسخة نظيفة للمسابقتين فقط، بدون أي سحب مواقع وبدون ESPN وبدون بث مباشر وبدون نتائج وبدون إشعارات.

## الملفات
ارفع الملفات التالية:

- `bot.py`
- `updater.py`
- `requirements.txt`
- `README_DEPLOY.md`

عند التشغيل لأول مرة، سيُنشئ البوت ملف:

- `contest_data.json`

هذا الملف يحفظ:

- أسماء المشاركين
- اختياراتهم
- المنتخبات المغادرة
- الإضافات والحذف

لا تحذف `contest_data.json` بعد التشغيل، لأنه ملف بيانات المسابقة اليدوية.

## التوكن
ضع توكن البوت في أحد متغيرات البيئة:

- `BOT_TOKEN`
- أو `TELEGRAM_BOT_TOKEN`
- أو `TELEGRAM_TOKEN`
- أو `TOKEN`

## التشغيل

```bash
pip install -r requirements.txt
python bot.py
```

أو:

```bash
python updater.py
```

## الأزرار

/start يعرض:

- 🏆 مسابقات المصيف

داخلها:

- 🏆 مسابقة أبوخالد
- 🏆 مسابقة أبوياسر
- 🛠️ إدارة المتسابقين

إدارة المتسابقين تطلب الرقم السري:

```text
الملحق
```

بعد الرقم تظهر:

- 🚪 منتخب غادر
- ♻️ استعادة منتخب
- ➕ إضافة متسابق
- 🗑️ حذف متسابق

## منتخب غادر
يعرض المنتخبات المختارة كأزرار مع الحالة:

- البرازيل 🟢 مستمر
- هولندا 🔴 مغادر

الضغط على المنتخب يجعله مغادرًا لكل من اختاره في مسابقة أبوخالد وأبوياسر.

## استعادة منتخب
يعرض المنتخبات المغادرة، والضغط عليها يرجع كل مختاريها إلى مستمر.

## إضافة متسابق
- اختر أبوخالد أو أبوياسر
- اكتب الاسم
- اكتب المنتخب
- إذا أبوياسر، اكتب اللاعب

## حذف متسابق
- اختر المسابقة
- اختر المتسابق
- أكد الحذف

## ملاحظة مهمة
هذه النسخة لا تتصل بأي موقع خارجي. الاتصال الوحيد هو Telegram لتشغيل البوت وإرسال الرسائل والصور.
